# Petfinder

Nx monorepo: Angular `apps/ui`, NestJS `apps/api`, shared `libs/shared/models`. See README.md for commands.

## Code style

- Comments: concise, and only for advanced or non-obvious logic. Explain *why*, such as a workaround, a tricky API or a hidden constraint, not *what*. Don't comment self-explanatory code or narrate steps.

## Workflow

- Build features BDD/TDD (see the `bdd-tdd` skill).
- Don't commit or push unless asked.
